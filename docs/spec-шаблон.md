## 1. Зачем это нужно (БТ — бизнес-требование)

Кто пользователь, какую его боль закрываем, какой результат он получает.
Простым языком, без техники. 3–5 предложений.

*Пример: управляющий после созвона тратит 40 минут на расшифровку и протокол. Хочет получать готовый протокол с решениями и задачами автоматически.* `[заказчик]`

## 4. Критерии приёмки

Формат **Дано → Когда → Тогда**. По каждому Юра должен уметь ответить «да/нет», не спрашивая автора.
Обязательно: минимум 2 граничных случая (пусто, ноль, огромный вход) и 1 защитный (ошибка / нет подтверждения / нет доступа).

- [ ] **Дано:** … **Когда:** … **Тогда:** …
- [ ] **Дано:** … **Когда:** … **Тогда:** …
- [ ] *(граничный)* **Дано:** пустой файл на входе. **Тогда:** … (не падает молча)
- [ ] *(граничный)* **Дано:** … **Тогда:** …
- [ ] *(защитный)* **Дано:** внешний сервис ответил ошибкой. **Тогда:** понятное сообщение, данные не портятся
