## Что я понял

Коммит - это изменение в проекте, то есть снапшот как в игре, где можно легко отследить каждое изменение в проекте формулировкой "что и зачем". маленький коммит - одно небольшое изменение за раз для того, чтобы если что либо сломалось легко найти проблему, нежели в гигантских коммитах.
Контроль версий нужен для того, чтобы файл постоянно не перезаписывался и можно было вернуться в определенную его версию и что-то поправить
git init — превращает обычную папку в git-репозиторий, создаёт скрытую папку .git, где будет храниться история
git clone — скачивает уже существующий репозиторий откуда-то вместе со всей историей
git status — показывает текущее состояние, что изменено, что новое
git add — помечает файл, как готовый к коммиту
git commit — берёт всё помеченное и записывает в историю как снапшот
git log --oneline — показывает историю коммитов
git diff — показывает построчно, что изменилось в файле по сравнению с последним снапшотом
