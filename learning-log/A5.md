## Что я понял

Удалённый репозиторий - та же история коммитов, только облачная копия на github
push - отправить коммиты
pull - скачать их
branch - подвижная метка на коммите, позволяет работать над чем-то отдельно, не трогая основную версию
pull request - твои личные изменения в проекте, которые отправляются на проверку, чтобы не трогать мейн
merge-конфликт - одновременное изменение пересекающихся строк, где вручную нужно решить что пойдет в изменение 
checkout - переключение между сохранениями
