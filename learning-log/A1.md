## Что я понял

Shell - это пространство в ОС где все можно сделать отдельными командами, создать папку, удалить ее, переименовать, в обшем все, что можно сделать где либо мышкой, в shell можно сделать текстом. такие обозначения как точка или две точки используются для сокращения, чтобы не писать целый путь. 
TAB - это автодополнение для экономии времени. 
PATH - список папок среди которых shell ищет файл с заданным названием, и в случае отсутствия таких файлов, выводит ошибку причем только расширения .bat \ .exe \ .cmd
Cat - выводит содержимое файла в терминал не открывая редактор
Cp - копирует файл, появляется копия с новым именем
Mv - перемещает файл между папками, нужно указать откуда и куда, если все в пределах одной папки, можно использовать в качестве переименования файла 
Rm - удаляет файл, папку сразу без переноса в корзину
