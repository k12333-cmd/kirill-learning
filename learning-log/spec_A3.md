# Спека: <Скрипт подсчёта расходов по категориям>

## 1. Зачем это нужно

пользователь ведёт учёт расходов в текстовом файле и вручную считает суммы по категориям, это долго и легко ошибиться. Хочет получать готовый отчёт по категориям автоматически

## 2. Что система делает 

1. берет данные из файла, группирует их на "КАТЕГОРИЯ, сумма"
2. считает сумму одной категории и среднюю сумму в ней
3. дает общий вывод данных из "категория-сумма, среднее количество", а также сумма по всем категориям
4. если в файле кривая строка типа еда,abc — скрипт её пропускает, пишет предупреждение, не падает

## 3. Данные, зависимости, побочки

откуда берёт данные - из файла расходы.csv, который лежит в той же папке, что и сам скрипт

от чего зависит - внешних API и ключей нет. Зависит только от формата файла: каждая строка должна быть категория,число

что меняет/пишет - ничего не пишет и не меняет, только выводит текст в консоль. побочек нет.

## 4. Критерии приёмки

- [ ] **Дано:** файл содержит строку еда,4787 **Когда:** запускаю скрипт **Тогда:** на экране выводится еда : всего 4787 , среднее 4787.0 и Общая сумма по всем категориям: 4787
- [ ] **Дано:** файл содержит строки еда,100 и транспорт,50 **Когда:** запускаю скрипт **Тогда:** на экране выводится еда : всего 100 , среднее 100.0, транспорт : всего 50 , среднее 50.0 и Общая сумма по всем категориям: 150
- [ ] *(граничный)* **Дано:** пустой файл на входе. **Тогда:** на экране выводится только Общая сумма по всем категориям: 0, ни одной строки по категориям, скрипт не падает
- [ ] *(граничный)* **Дано:** файл содержит строку еда,0 **Тогда:** на экране выводится еда : всего 0 , среднее 0.0 и Общая сумма по всем категориям: 0, скрипт не падает
- [ ] *(защитный)* **Дано:** файл содержит строку еда,abc **Тогда:** строка еда,abc пропускается с сообщением о пропуске, еда : всего 4787 , среднее 4787.0 считается верно, скрипт не падает

## 5. Чего НЕ делаем (non-goals)

- НЕ сортирует вывод по сумме или по алфавиту - категории идут в том порядке, в котором встретились в файле
- НЕ поддерживает другие форматы файлов, только csv с запятыми, категория,число
